# 3D-sunglasses-using-spline

Hi!

This is my first creation utilizing Spline, which I have found to be very user friendly. My aim was to create a pair of 3D glasses which I could use to model an AR experience I've been working on.

The concept is to use AR capabilities to innovate Syntonic Phototherapy. The glasses would be connected to a mobile app akin to those used with colored lightbulbs where you can control your experience and type of Syntonic Phototherapy you would like to receive.
